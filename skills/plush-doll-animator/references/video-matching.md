# 对齐其他参考视频

只有用户给了新的动作参考或要求改参数时才需要重新测量。默认直接使用 `assets/motion.json`。

- 用视频原始帧率与逐帧采样测周期。固定取整数秒或半秒可能刚好命中同一相位，误以为视频静止。
- 在开头、中段、结尾各取多个周期，跟踪同一玩偶头顶、五官间距或稳定轮廓，比较重复帧间隔。周期 = 重复间隔帧数 / fps。
- 分清正常状态、最高状态和最扁状态。分别测相对于正常状态的纵向和横向比例；不要把“最扁约最高的一半”误写成“相对正常高度压缩一半”。
- 头部在最高时可能超出正常高度。脚底固定与向上拉伸可以同时成立。
- 前景遮挡、透视和布偶自身厚度会影响测量；记录所用参照点，并将结果表述为估算。不要把像素轮廓比率称为精确的 3D 模型缩放。
- 修改项目内配置副本，通过 `--config` 传入；周期必须能被 `frame_duration_ms` 整除，GIF 帧时长须为 10ms 的倍数。
- 检查新极值是否裁切，再检查整圈时长和循环接缝。
